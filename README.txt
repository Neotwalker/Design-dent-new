Креативный редизайн сайта стоматологии «Дизайн Дент».

Что внутри:
- index.html — главная страница с hero, услугами, акциями, врачами, отзывами, контактами.
- price.html — страница цен и акций.
- specialists.html — страница врачей.
- reviews.html — страница отзывов.
- assets/style.css — весь дизайн и адаптив.
- assets/script.js — анимации: split title, scroll reveal, scroll progress, magnetic buttons, cursor glow, modal, mobile menu.

Как открыть:
1. Разархивируйте ZIP.
2. Откройте index.html в браузере.

Примечание:
Это статический HTML-прототип. Формы демонстрационные. Для WordPress можно перенести секции в шаблоны темы и заменить статичный контент на ACF/CF7.
