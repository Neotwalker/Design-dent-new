# Design Dent — desktop stage 11

Этап продолжает desktop-полировку главной страницы и закрывает новые замечания по UX/UI.

Изменено:
- блок «Лицензии и сертификаты» переделан в горизонтальный слайдер с кнопками навигации;
- слайдер документов рассчитан на будущий рост числа сертификатов: на desktop показывает несколько карточек, на tablet/mobile скроллится адаптивно;
- блок «До / после» подправлен для широких экранов: композиция снова занимает всю доступную ширину колонки и держит одинаковую высоту с карточкой результата;
- изображения в before/after остаются видимыми целиком и центрируются внутри блока;
- карточки услуг стали кликабельными целиком и получили keyboard-access поведение (Enter / Space), без конфликта с drag-scroll;
- карточки специалистов на desktop переведены в горизонтальный формат на всю ширину секции;
- на меньших брейкпоинтах карточки специалистов остаются вертикальными;
- обновлена логика phone mask: поле не стартует со значением `+7`, сохраняет placeholder и корректно удаляет цифры по Backspace.

Важно:
- документы по-прежнему подключены по прямым URL со старого сайта. При интеграции в WordPress лучше заменить их локальными attachment URLs;
- карточки услуг пока ведут на `#`, так как отдельные страницы услуг ещё не заведены.
