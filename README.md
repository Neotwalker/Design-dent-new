# Design Dent — tablet/mobile stage 18

Изменено:
- модальное окно заявки больше не выезжает снизу: фон плавно проявляется, а `lead-modal__dialog` масштабируется `0 → 1`; закрытая модалка остаётся в DOM с `z-index:-1`;
- cookie banner остаётся смонтированным и скрывается ниже viewport через `bottom:-100%`;
- blog slider на планшете стал уже, чтобы был виден небольшой фрагмент следующей карточки;
- на телефонах blog-card и doctor-card уменьшены по ширине, следующая карточка слегка видна;
- на мобильных снова показан текст «Записаться к врачу»;
- сертификаты на телефонах и малых планшетах выводятся по две карточки в горизонтальном rail, scrollbar скрыт;
- закрытие burger-menu сохраняет исходную позицию страницы и возвращает focus без прокрутки;
- mobile video trigger перенесён в верхний правый угол hero, чтобы не перекрывать текст, и получил лёгкую pulse-анимацию с поддержкой `prefers-reduced-motion`.
