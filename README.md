# Design Dent - homepage prototype

Static responsive homepage prepared for GitHub Pages / GitHub Deployer.

## Structure
- `index.html` - homepage
- `assets/css/style.css` - styles
- `assets/js/app.js` - interactions
- `assets/img/` - local images and logo
