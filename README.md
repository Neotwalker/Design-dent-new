# Design Dent — desktop stage 14

Изменено:
- у слайдера услуг убрано перетаскивание мышью/трекпадом на desktop;
- на desktop услуги листаются только кнопками-стрелками;
- карточки услуг остаются полноценными ссылками и больше не конфликтуют с drag-scroll;
- на touch-устройствах сохранён нативный горизонтальный свайп;
- Swiper не добавлялся: текущий вариант легче и не требует внешних или локальных библиотек.

Если позже понадобится единая библиотека для всех каруселей, Swiper можно подключить локально в `assets/vendor/`, без CDN.
