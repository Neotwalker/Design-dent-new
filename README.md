# Design Dent — tablet stage 17

Исправлено:
- hero в диапазоне 621–920 px уменьшен до 550 px и переразложен, чтобы теги не пересекались с карточкой основателя;
- Яндекс-виджет отзывов на планшетах масштабируется пропорционально на всю доступную ширину контейнера;
- блог на <=920 px переведён в full-bleed горизонтальный rail без видимого scrollbar и без обрезания карточек по краям;
- врачи на <=920 px также переведены в горизонтальный rail; карточки уменьшены и сделаны компактнее, на телефонах показывается одна полноценная карточка;
- модальное окно формы теперь плавно въезжает/уезжает за экран, без `display:none`;
- success-modal и inline-success также остаются смонтированными и скрываются перемещением/visibility;
- cookie banner больше не скрывается через `display:none`: в неактивном состоянии он находится ниже viewport и плавно появляется снизу.

Примечание:
- для Яндекс-отзывов используется пропорциональное масштабирование официального iframe на tablet, потому что внутренний cross-origin layout Яндекса имеет фиксированную рабочую ширину и не может быть стилизован из нашего CSS.
