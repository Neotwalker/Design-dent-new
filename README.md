# Design Dent — desktop stage 12

Этап закрывает новые замечания по desktop-версии.

Изменено:
- блок «До / после» переработан для wide desktop: левая колонка растягивается по ширине, а изображения внутри снова заполняют блок по ширине;
- карточки врачей на больших экранах уменьшены по высоте и стали компактнее;
- если в слайдере все элементы помещаются без прокрутки, стрелки навигации автоматически скрываются;
- в блоке «Лицензии и сертификаты» убрана ссылка «Открыть исходный сайт»;
- в блоке «Услуги» улучшена кликабельность карточек: целиком карточка реагирует как ссылка, drag-scroll не стартует при клике по интерактивным элементам;
- убрано вертикальное обрезание hover-эффекта карточек услуг.

Важно:
- ссылки карточек услуг по-прежнему тестовые (`#`) — при подключении реальных страниц услуг их нужно заменить на рабочие URL.
