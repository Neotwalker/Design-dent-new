# Design Dent — desktop stage 13

Изменено:
- удалён skip-link;
- каждая карточка услуги теперь является настоящей ссылкой `<a>` целиком, без вложенной ссылки и JS-прокси;
- добавлены рабочие временные страницы для шести услуг, поэтому в GitHub Pages переходы не ведут на `#` и не дают 404;
- drag-scroll услуг сохранён: обычный клик открывает услугу, заметное перетаскивание отменяет навигацию;
- карточки специалистов на desktop ограничены примерно 460 px по высоте, на 1600+ — 480 px;
- на tablet/mobile прежняя вертикальная адаптивная компоновка врачей сохраняется.

В WordPress временные `/services/.../` страницы будут заменены на постоянные ссылки CPT/страниц услуг.
