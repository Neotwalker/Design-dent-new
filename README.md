# Design Dent — tablet/mobile stage 19

Исправлено:
- скрытый `lead-success` больше не уезжает вниз через transform и не растягивает scroll-area модального окна;
- success overlay теперь скрывается через scale/opacity/z-index и появляется без пустого белого блока;
- сертификаты на ширине <=620px переведены в стабильный flex-rail: карточки одинаковой ширины, третья больше не растягивается;
- video CTA на 621–768px перенесён в верхний правый угол hero и больше не должен пересекать заголовок;
- после активации карты iframe получает `pointer-events` и touch-жесты; автоматическое отключение карты при тапе вне неё убрано;
- переходы по внутренним якорям перехвачены JS и выполняются плавно с учётом высоты sticky-header;
- переход из открытого burger-menu к якорю также сначала корректно закрывает меню, затем плавно прокручивает страницу.
