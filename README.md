# Design Dent — desktop stage 10

Текущий этап продолжает desktop-полировку главной страницы.

Изменено:
- полностью переработан cookie banner: улучшена иерархия, увеличены вторичные действия, добавлен отдельный outlined CTA «Только необходимые» и заметная ссылка «Подробнее о cookies»;
- добавлена отдельная визуальная метка cookies и более спокойная адаптивная композиция;
- раздел «Лицензии и сертификаты» теперь использует три реальные изображения документов, предоставленные клиникой;
- документы открываются через Fancybox как единая галерея;
- preview документов не обрезается (`object-fit: contain`), карточки имеют hover/focus-поведение;
- сохранена адаптация gallery/cookie UI для tablet/mobile.

Важно перед WordPress-интеграцией:
- три документа сейчас используются по прямым URL старого сайта. При переносе темы их лучше импортировать в Media Library и заменить URL на локальные attachment URLs;
- ссылка «Подробнее о cookies» пока ведёт на `#`, до появления финальной страницы политики cookies/privacy;
- cookie preference хранится в localStorage как и на предыдущем этапе.
